# Изменения

## [1.0.0] - 2026-11-11

Первый выпуск.

### Поиск устройства

- Автоматическое определение известных дек с подсказкой о совместимости с прошивкой AKP153R.
- Поиск незнакомой деки по разнице списков USB-устройств до и после подключения, ручной выбор из списка.

### Сбор данных

- Дескрипторы устройства, конфигурации и BOS, строки, HID report descriptor и размеры отчётов.
- Чтение Feature-отчётов запросом GET_FEATURE, включая недекларированные ID 0..15; в отчёт попадают только ответившие.
- Запись Input-отчётов во время нажатий кнопок и поворота энкодеров.
- Необязательный сбор сведений о незнакомой деке в режиме обновления.

### Отчёт и запуск

- Отчёт в JSON по схеме 2 с моделью, способом входа в режим обновления и признаком `declared` у Feature-отчётов.
- Форма запроса прошивки с автоматическим заполнением модели; ссылку и фотографии пользователь добавляет в форме.
- Интерфейс на русском и английском по языку системы.
- Windows x64 и ARM64, macOS Apple Silicon и Intel, Linux x64.
